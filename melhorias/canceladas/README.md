# canceladas/

Propostas avaliadas e **rejeitadas** — decisão explícita de não implementar, diferente de `adiadas/` (que aguardam gatilho/prioridade futura) e de `backlog/` (que nunca foram avaliadas).

Nenhuma proposta se enquadra aqui hoje (2026-08-01) no nível de arquivo inteiro — quando algo foi rejeitado, foi como sub-item de uma proposta parcialmente implementada (ver `melhorias/MANIFESTO_MELHORIAS.md`). Quando uma proposta inteira for avaliada e recusada, mova o `.md` para cá e registre o motivo no manifesto.
